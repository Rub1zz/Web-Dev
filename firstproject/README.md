# Snapshots – A Beginner's Guide to Photography

CS1080A First Project by Micheal & Riley.

## Purpose
An informational website that introduces beginners to photography: types of photography, beginner gear, and tips for taking better photos.

## Pages
- `index.html` – Home page with an intro and types of photography
- `gear.html` – Table of beginner gear and what to buy first
- `tips.html` – Photo tips and basic camera settings

## Key Features
- Semantic HTML (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Headings, paragraphs, ordered and unordered lists, links, images and a table
- CSS color scheme, typography, and styled lists and tables
- Margin, padding and borders for layout
- Flexbox for the navigation bar and card rows
- Media query that stacks the layout on screens under 700px
